Sync Attendance from Discord

Scans #cave-attendance for the selected month, matches each message's attendee list against the roster (name or alias, fuzzy — handles typos and shortcuts), and logs attendance onto the matching boss log, creating it if it doesn't exist yet. Posts a confirmation back into the channel for each one.

Fix Merged Attendance

One-time cleanup for attendance records logged before each Discord message tracked its own session — those got wrongly combined whenever the same boss was killed more than once on the same day. This re-fetches each affected message, splits it back into one record per kill (moving any existing loot onto the earliest one), and never touches anything already logged correctly. Safe to run more than once.
